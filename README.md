# 📖 ReadEase AI

**ReadEase AI** is a simple, user-friendly document reader that helps people read documents more comfortably using text-to-speech.

## ✨ Features

- Upload PDF, DOCX and DOC documents.
- Extract and display document text.
- Select PDF pages to read.
- Listen to text using text-to-speech.
- Choose available voices.
- Adjust reading speed.
- Play, pause, resume and stop speech.
- Follow along with sentence highlighting and automatic scrolling.

## 🛠️ Technologies Used

- Python
- Streamlit
- PyMuPDF
- python-docx
- HTML, CSS and JavaScript
- Browser Speech Synthesis API

## 🚀 Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/naazsultana555/ReadEaseAI.git
   ```

2. Open the project folder:
   ```bash
   cd ReadEaseAI
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:
   ```bash
   python -m streamlit run app.py
   ```

5. Open the local URL shown in your terminal.
